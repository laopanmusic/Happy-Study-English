# Happy-Study-English
为小学生学习英语而开发的单词配对小游戏。

## 游戏介绍
这是一款专为小学三到六年级学生设计的英语单词记忆游戏。通过趣味的配对游戏方式，帮助孩子们快速记忆英文单词及其中文翻译。

## 游戏特色
- 🎯 **适合年龄**: 针对小学三年级到六年级学生
- 📚 **分级词汇**: 根据不同年级提供相应难度的单词
- 🎮 **趣味玩法**: 采用配对游戏机制，寓教于乐
- 🏆 **进度系统**: 关卡递进，逐步增加难度
- 🎨 **精美界面**: 色彩丰富，吸引孩子注意力

## 如何游玩
1. 打开 `index.html` 文件即可开始游戏
2. 选择对应的年级
3. 点击卡片，找到英文单词和对应的中文翻译
4. 配对成功获得分数，完成所有配对进入下一关

## 游戏规则
- 每次可以翻开两张卡片
- 找到英文单词和对应中文翻译的配对
- 配对成功得10分
- 完成所有配对后进入下一关
- 关卡越高，卡片数量越多，难度越大

## 技术实现
- 纯HTML + CSS + JavaScript实现
- 无需任何依赖或框架
- 响应式设计，支持不同屏幕尺寸

## 词汇内容
- **三年级**: 基础日常单词（apple, book, cat等）
- **四年级**: 常用名词和动词（animal, family, jump等）
- **五年级**: 进阶词汇（adventure, computer, festival等）
- **六年级**: 学科相关词汇（astronomy, geography, technology等）

## 开始使用
直接用浏览器打开 `index.html` 文件即可开始游戏！
